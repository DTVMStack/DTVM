# 检查清单生成

为特定领域生成检查清单，确保开发过程中的质量控制和完整性验证。

## 用户输入

你输入的内容即为上下文。应指定需要生成检查清单的领域或功能。

## 执行步骤

### 1. 确定清单领域

分析用户输入以确定：
- 清单的领域（例如：UX、安全、性能、可访问性）
- 项目的具体上下文
- 任何相关标准或法规

### 2. 检查清单模板

检查是否存在相关的清单模板：
- `.specify/templates/checklist-template.md`
- 任何特定领域的清单模板

### 3. 生成清单项目

为确定的领域生成适当的清单项目。清单应包括：

#### 内容质量
- 内容完整性和准确性
- 清晰度和简洁性
- 适当的详细程度

#### 功能性
- 功能完整性
- 边缘情况处理
- 错误处理

#### 用户体验
- 可用性
- 可访问性
- 性能
- 响应式设计

#### 技术质量
- 代码质量
- 测试覆盖率
- 文档完整性
- 安全考虑

#### 合规性
- 法律/法规要求
- 组织标准
- 行业最佳实践

### 4. 创建清单文件

在适当的位置创建清单文件：
- 功能清单：`FEATURE_DIR/checklists/requirements.md`
- 领域清单：`specs/checklists/DOMAIN.md`

### 5. 格式化清单

使用一致的格式：

```markdown
# Checklist: [名称]

## [类别]

- [ ] 检查项目 1
- [ ] 检查项目 2
- [ ] 检查项目 3

## Notes

[任何额外说明或上下文]
```

### 6. 报告

报告清单文件的位置和项目总数。
